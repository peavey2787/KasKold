Security

      
KasKold Web Vault enforces portable session policies inside the Rust signing boundary. Hardware RTC, eFuse, and device-bound storage guarantees remain properties of the physical M5 signer.

      

        
        
        
        
      

    


    

      
No-Sign Until

      
On M5 this policy is permanent and enforced by the hardware RTC. Web Vault can enforce the same UTC rule only for this running session because the host clock is not tamper-resistant.

      
      

      
    


    

      
Weekly Signing Windows

      
On M5 configured windows are permanent and hardware-RTC enforced. Web Vault uses the same parser/evaluator for this session, but the computer clock is not a hardware trust anchor.

      
      

      
    


    

      
Duress Credential

      
The M5 duress credential is an irreversible authenticated device feature: entering it wipes internal user data and it cannot later be disabled or changed.

      
Web Vault does not create a weaker software imitation. Use the physical M5 signer when this security property is required.
