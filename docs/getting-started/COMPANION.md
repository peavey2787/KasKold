# Getting Started - Companion

KasKold Companion is always watch-only.

1. Open Companion Web, Android, or iOS.
2. Load/manage a **kpub** exported by KasKold Hardware or a KasKold Vault app.
3. Use the public wallet tools to inspect balances/history and construct transactions.
4. For a spend, send the generated signing request to Hardware/Vault and review it there.
5. Return the signed response to Companion and broadcast.

**Broadcast TX** and **Multisig** are available directly from the startup surface. Companion never asks you to create/restore a private wallet and never offers local signing.
