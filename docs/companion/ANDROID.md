# Companion Android

KasKold Companion Android is a thin native shell around the same watch-only Companion Web/Rust runtime. It does not create/restore wallets, store private keys, or sign locally.

The Android shell provides platform integration such as WebView hosting and native settings. Software custody belongs to the separate **KasKold Vault Android** app.
