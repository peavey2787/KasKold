# Companion iOS

KasKold Companion iOS is a thin native shell around the same watch-only Companion Web/Rust runtime. It does not create/restore wallets, store private keys, or sign locally.

The iOS shell provides platform integration around public watch-only state. Software custody belongs to the separate **KasKold Vault iOS** app.
