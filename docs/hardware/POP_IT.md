# KasKold Pop It!

KasKold Pop It! is the advanced provisioning/secure-boot workflow for supported KasKold Hardware. It is security-sensitive: use the repository's current provisioning and eFuse runbooks rather than copying commands from older releases.

See [Pop It! Secure Boot](../security/POP_IT_SECURE_BOOT.md) and the [eFuse runbook](../security/EFUSE_RUNBOOK.md).
