# M5Stack CoreS3 Lite

CoreS3 Lite shares the CoreS3 hardware adapter through a declarative board profile rather than a duplicated firmware implementation.

**Status: build-supported / expected compatible; hardware qualification pending.** It must not be represented as production-qualified until real-device testing covers boot, display, touch, camera, QR scan/display, SD, entropy inputs, seed creation, signing, backup/restore, secure-boot/provisioning paths, power/reboot behavior, and firmware update behavior.
