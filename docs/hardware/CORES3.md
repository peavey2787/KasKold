# M5Stack CoreS3

M5Stack CoreS3 is the primary **hardware-qualified** KasKold Hardware target. The firmware uses the CoreS3 M5Stack board adapter for display, touch, camera, SD, power management, RTC, and hardware-specific entropy inputs.

Production/release tooling targets the qualified CoreS3 profile. Device release qualification must still include the repository's HIL/security/reproducibility procedures on real hardware before publishing a release artifact.
